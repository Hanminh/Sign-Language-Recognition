# Đề tài:  Nhận diện ngôn ngữ ký hiệu liên tục tiếng Việt - Vietnamese Continuous Sign Language Recognition


## 1. Dữ liệu

Download bộ dữ liệu tại link https://drive.google.com/file/d/1aYfPelum1tFw2gAC7wWaZdC7JoxSb7ch/view?usp=sharing 

## 2. Chạy mô hình

- Giải nén bộ dữ liệu
- Điều chỉnh đường dẫn tương ứng trong file .env
- Điều chỉnh các siêu tham số tròng file argument.py
- Chạy file model_corrnet_train_vn.py để huấn luyện mô hình
